# Teaching & Learning

**Visit the site:** https://juan-zhong.github.io/teaching/

Teaching materials, learning resources, and tools for exploring language, by Juan Zhong (钟娟/鍾娟), PhD student in Linguistics at the University at Buffalo, SUNY.

The site includes:

- **Teaching materials**: assignments, lecture slides, and teaching notes for courses in linguistics, free to adapt
- **Tools & guides**: guidelines for using generative AI tools responsibly in literature searches
- **Language learning**: Anyuan Hakka for learners
- **Community resources**: linguistics taught in Anyuan Hakka and other community-based work
- **Further resources**: dictionaries, corpora, and archives for Chinese languages
- **Language in Music and Film**: a listening and viewing list for the languages of Eastern Asia

Related: [Juan Zhong](https://juan-zhong.github.io/me/) · [AYHAK · Anyuan Hakka Documentation Project](https://juan-zhong.github.io/ay_hak/)
